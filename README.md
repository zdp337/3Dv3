# 单猫MVP（微信小程序初始可验收版本）

当前交付物已经从浏览器静态 Demo 补齐为**微信开发者工具可运行的小程序工程**。根目录保留静态原型文件，同时新增 `miniprogram/` 作为真正的小程序源码目录。

## 微信开发者工具运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前仓库根目录：`e:/kb1/20260517190212/20260517190212`。
4. AppID 可选择“测试号”或使用配置中的 `touristappid`。
5. 导入后点击“编译”，即可在模拟器中验收。

> 已在根目录提供 `project.config.json`，其中 `miniprogramRoot` 指向 `miniprogram/`。

## 小程序当前可验收功能

- 首页双场景整图渲染（猫咖 / 古风庭院）
- 同屏最多 4 只猫咪展示与自动漫游
- 点击猫咪后显示互动面板，默认隐藏互动按钮和数值
- 每日互动（抚摸 / 喂食 / 玩耍）与成长值/等级联动
- 底部“祈愿”触发全屏仪式，并生成今日祈愿卡
- 图鉴三分栏：卡片收藏 / 祈福日历 / 场景图鉴
- 右侧入口：设置 / 好友 / 邮件（好友和邮件当前为占位提示）
- 设置页支持切换场景、修改选中猫咪昵称
- 设置页验收工具：重置今日次数、清空全部存档

## 验收建议流程

1. 在首页点击任意猫咪，确认互动面板出现。
2. 点击抚摸/喂食/玩耍，确认成长值、心情、次数变化。
3. 点击底部“祈愿”，确认全屏仪式完成并生成祈愿卡。
4. 点击“查看图鉴”，确认卡片收藏新增记录。
5. 切换到“祈福日历”，确认当天日期高亮并显示场景标记。
6. 切换到“场景图鉴”，确认当前祈愿场景已解锁。
7. 进入设置页切换场景，回首页确认背景图和猫咪点位变化。
8. 使用“重置今日次数”后，再次验证互动和祈愿流程。

## 小程序文件结构

- `project.config.json`：微信开发者工具项目配置
- `miniprogram/app.json`：小程序全局配置
- `miniprogram/app.js`：小程序全局入口
- `miniprogram/app.wxss`：小程序全局样式
- `miniprogram/pages/index/index.wxml`：首页/图鉴/设置页面结构
- `miniprogram/pages/index/index.wxss`：页面样式
- `miniprogram/pages/index/index.js`：页面业务逻辑
- `miniprogram/assets/cafe.jpg`：猫咖整图资源
- `miniprogram/assets/courtyard.jpg`：庭院整图资源

## 规则说明（当前实现）

- 成长值：抚摸 +2、喂食 +3、玩耍 +5、祈愿 +8
- 每日上限：抚摸 10 次、喂食 5 次、玩耍 5 次、祈愿 1 次
- 每日重置：按本地日期（YYYY-MM-DD）自动刷新次数
- 数据持久化：使用微信小程序本地存储 `wx.setStorageSync`

## 静态 Demo 说明

根目录 `index.html`、`styles.css`、`app.js` 仍保留为浏览器静态原型备份；本轮验收请以 `miniprogram/` 小程序工程为准。
